07. Contrats de Données
Périmètre de ce fichier
Ce fichier décrit les contrats de données qui circulent entre les blocs du système. Un contrat de données définit :

l'émetteur (bloc source)
le récepteur (bloc cible)
la structure exacte des champs échangés (nom, type, origine)
les règles ou contraintes attachées
Les contrats sont extraits fidèlement des workflows n8n réels (pas de reconstruction théorique).

Vue d'ensemble
Le système fait circuler 11 contrats de données au total :

6 contrats internes au Workflow 1
1 contrat inter-workflow (WF1 vers WF2)
4 contrats internes au Workflow 2

CT-08 — Prospect brut base de données
Source : SQL_Get_Prospects (Postgres executeQuery)
Cible : Set_AI_Input

Requête SQL exécutée :
SELECT p.* FROM prospects p JOIN collectes c ON p.place_id = c.place_id WHERE c.id_campagne::text = id_campagne reçu.

CT-10 — Réponse Claude (JSON en texte)
Source : AI_Claude_Prospect_Analysis (Anthropic Claude Sonnet)
Cible : Parse_AI_And_Merge

Structure attendue (contrat imposé par le prompt) :

angle : string, 10 mots max, angle de prospection
accroche : string, phrase d'approche courte
priorite : string, chiffre entre 1 et 5
Format réel retourné par Claude :
La réponse est encapsulée dans content[].text avec potentiellement des balises Markdown de type triple-backtick json autour. Le nettoyage est géré côté Parse_AI_And_Merge.

Fallback en cas d'échec de parsing :

angle : "Erreur de parsing"
accroche : chaîne vide
priorite : "0"
CT-11 — Prospect enrichi fusionné
Source : Parse_AI_And_Merge (Code JS)
Cible : Append row in sheet (Google Sheets)

Fusion de :

toutes les données brutes du prospect (depuis CT-08)
les 3 champs enrichis par l'IA (angle, accroche, priorite)
Logique de fusion (code JS) :
Spread de originalData (colonnes prospects) + spread de aiData (angle, accroche, priorite).

Injection dans Google Sheets — mapping vers colonnes :

Colonne Sheet	Origine	Note
Nom du lieu	nom	
Activité	recherche	
Adresse	adresse	
Téléphone	telephone	forçage texte via préfixe apostrophe
Site Web	site_web	
Email	email	
Note Google	note_google	typé string côté Sheet
Statut de qualification	statut	valeur initiale = À trier
Angle Prospection	angle	issu IA
Accroche	accroche	issu IA
Score	priorite	issu IA
Notes de format :

Le téléphone est préfixé par une apostrophe pour forcer le format texte dans Google Sheets (éviter la conversion numérique qui perdrait le 0 initial).
Les valeurs numériques (note, score) sont stockées en string côté Sheet pour compatibilité affichage.
